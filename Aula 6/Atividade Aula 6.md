1. Empatia - Como posso evitar me atrasar para meus compromissos?

2. Definição - Me acostumei a chegar atrasado nos lugares, mesmo lembrando e tendo tempo para se precaver desses atrasos.

3. Ideação
 1º - Criar uma rotina, demarcando horários para cada tipo de atividade feita no dia.
 2º - Ter um alarme com tempo estimando uma margem maior até o horário combinado.
 3º - Deixar pronto e organizado os objetos que serão utilizados para o compromisso.

4. Escolha - Criar uma rotina, demarcando horários para cada tipo de atividade feita no dia.

5. História de usuário
 1º - Como usuário, quero ter um calendário editável, para organizar os compromissos do mês.

 2º - Como usuário, quero poder visualizar as minhas rotinas, para acompanhar e organizar melhor as minhas atividades diárias. 

 3º - Como usuário, quero poder adicionar e editar minhas tarefas por horário, para manter minha rotina organizada e não esquecer dos meus compromissos.


6. Critério de aceitação
 1º - Dado que o usuário tenha uma rotina cadastrada, quando acessar a rotina do dia, então deverá visualizar todas as atividades organizadas por horário.

 2º - Dado que o usuário esteja visualizando sua rotina, quando adicionar ou editar uma tarefa, então a alteração deverá ser salva e aparecer no horário definido.

 3º - Dado que o usuário tenha um compromisso cadastrado, quando chegar próximo do horário definido, então o sistema deverá enviar um lembrete.
